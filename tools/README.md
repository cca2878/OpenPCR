# 工具

| 目录 | 用途 |
| --- | --- |
| OpenPCR.Runner | 战斗请求运行、JSON Lines 交互会话和检查点 |
| [OpenPCR.BattleEditor](../docs/tools/battle-editor.md) | 独立场景 JSON 的创建、查询、编辑与准备校验 |
| [OpenPCR.PrefabExtractor](../docs/tools/prefab-extractor.md) | 离线 bundle 提取、manifest 建库与数据库比较 |
| OpenPCR.Transcription | UUID 登记和优化区域结构的构建检查 |
| tests | BattleEditor 无资源测试和显式指定资源集的集成测试 |

构建和测试命令见 [构建与测试](../docs/development/build-and-test.md)。工具不附带游戏数据，资源及网络地址由调用者显式提供。
